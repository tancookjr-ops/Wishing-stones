Warm pill-shaped call-to-action — use for the main action on a screen (Plan your visit, Add to basket).

```jsx
<Button variant="primary" size="lg">Plan your visit</Button>
<Button variant="outline">See the gallery</Button>
```

Variants: `primary` (coral), `secondary` (deep-sea ink), `outline`, `ghost`. Sizes: `sm` / `md` / `lg`. Pass `as="a"` with `href` for links.
